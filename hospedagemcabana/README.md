# Hospedagem Cabana — Rio Vale

Landing page demonstrativa da Cabana Rio Vale, em Nova Roma do Sul/RS.

## Executar
Abra `index.html` diretamente no navegador ou use Live Server.

## Estrutura
- `index.html`: HTML, CSS e JavaScript em um único arquivo.
- Fotografias carregadas remotamente a partir do portal de turismo de Nova Roma do Sul.

## Reservas
No fim do arquivo, altere a constante `AIRBNB_URL` para o link **direto** do anúncio da cabana. Enquanto não houver URL confirmada, os botões levam à busca do Airbnb na região, não à página específica.

## Observação
Projeto de demonstração não oficial. Antes de divulgar comercialmente, obtenha autorização para uso das fotografias e marca.

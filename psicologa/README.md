## Uso
A versão publicada em `index.html` é **autônoma**: CSS, JavaScript e as imagens estão incorporados nela para evitar caminhos quebrados. Arquivos antigos `styles.css`, `script.js` e `config.js` não são usados por esta versão. Para editar o design modular, veja o ZIP de entrega.\n\nAbra `index.html` em navegador ou hospede a pasta completa como site estático. Vercel: projeto com root directory `psicologa` quando publicado no repositório `palomagl/landingpages`.
